背景音乐说明
==============

页面会自动按顺序尝试读取以下音频（第一个能加载的就会播放，循环，音量渐入 52%）：

1. music/faruxue.mp3     ← 推荐，把《发如雪》重命名成这个名字放这里
2. music/发如雪.mp3
3. music/bgm.mp3
4. bgm.mp3               ← 也可以直接丢在仓库根目录

怎么放：
- GitHub 网页：进入仓库 → Add file → Upload files → 拖入 mp3 → 在文件名前补上 `music/` → Commit
  （目录不存在时 GitHub 会自动创建）
- 或者把 mp3 发给我，我直接帮你传上去。

注意：
- 手机浏览器不允许“自动播放”，必须等用户第一次点屏后才会开始放，这是浏览器策略，不是 bug。
- 右上角的小音符按钮可以随时开/关音乐。
- 没有音频文件时页面不会报错，只是没有背景音乐。
