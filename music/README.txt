背景音乐说明
==============

现在页面自带一首“无版权氛围纯音乐”，不需要任何音频文件：

- 实现方式：WebAudio 实时合成（C 大调长音铺底 + 五声音阶随机琶音 + 3.6 秒卷积混响）
- 特点：无限循环、没有接缝、没有任何版权问题、文件体积为 0
- 第一次触摸屏幕后才会响起（手机浏览器禁止自动播放，这是系统策略）
- 右上角 ♪ 按钮可以随时开/关

可选：如果你想换成自己的歌（比如《发如雪》）
--------------------------------------------------
页面会按下面顺序找音频文件，只要第一个能加载，就会自动切换成播放你的音乐（内置合成音乐淡出）：

1. music/faruxue.mp3     ← 推荐
2. music/发如雪.mp3
3. music/bgm.mp3
4. bgm.mp3               ← 也可以直接丢在仓库根目录

怎么放：
- GitHub 网页：仓库 → Add file → Upload files → 拖入 mp3 → 文件名前补上 `music/` → Commit
- 或者把 mp3 发给我，我直接帮你传上去。

注意：自己上传的商业音乐属于个人使用，公开页面播放有版权风险，自己留着自己看没关系。
